# Lab 01 C Sharp Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Hoàn thiện 17 ứng dụng Console của Lab 01, báo cáo Word tiếng Việt có trang bìa và watermark, gói ZIP nộp bài và lịch sử Git rõ ràng.

**Architecture:** Mỗi bài là một project .NET 8 độc lập dưới thư mục `BaiNN`, chứa phần giao tiếp Console trong `Program.cs` và các phương thức/lớp có thể kiểm thử trực tiếp. Một project Console không dùng thư viện ngoài đóng vai trò bộ kiểm thử với các assertion thủ công. Báo cáo được sinh bằng `python-docx`, render qua LibreOffice đóng gói sẵn và kiểm tra từng trang trước khi đưa vào ZIP.

**Tech Stack:** C# 12, .NET 8 SDK, MSBuild solution, PowerShell, Python 3, python-docx, OOXML VML watermark, Git.

**Spec:** `docs/superpowers/specs/2026-09-17-lab01-csharp-design.md`
